ChargeBridge Evaluation Kit – Universal Breakout Board for AC & DC

The ultimate tool for charging station development. This breakout board makes all ChargeBridge module interfaces accessible via convenient connectors, serving as a flexible foundation for both AC and DC application.

Key Features:
  • Versatile: Supports development for both AC and DC fast charging (CCS) scenarios with full DIN SPEC 70121/ISO15118-2/-20 support
  • Ethernet or USB connection to Linux host
  • Interfaces: Full access to CAN (for power supplies), RS485 (for insulation monitors/meters), UART, 3x relay drivers, temperature measurements, emergency I/O and GPIOs.
  • Lab Ready: Perfect for desk setups, HIL test benches, as a reference design for custom carrier boards or for your fully fledged PoC Charger
  • Compatibility: Designed for the ChargeBridge Module (M.2) and seamless EVerest integration.
  • DC Capability: Enables testing of DC charging sequences up to 1000V when connected to external HV component.
  • 12V-24V supply voltage

 

Documentation: https://link.pionix.com/chargebridge-demo-docs

Open Hardware KiCad project files: https://github.com/PionixPublic/cb-eval-board

What you get:

  • EVAL Charging Carrier Board
  • ChargeBridge CB-CCS-EVSE-LU Module
  • 24V Power supply
